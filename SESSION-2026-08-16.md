## 2. Cameras in Frigate

Configured live on the LXC (`/opt/frigate/config/config.yml`) via Frigate Configuration Editor.

### Reolink RLC-810A (`front_door`, `back_yard`)

Camera app:
1. Enable **RTSP** (port 554)
2. Set **static IP**
3. Clear/Main → **H.265**; Fluent/Sub → **H.264**
4. Enable microphone / AAC audio if available

Frigate pattern:

```yaml
  front_door:
    enabled: true
    ffmpeg:
      inputs:
        - path: rtsp://admin:PASSWORD@192.168.68.124:554/h264Preview_01_sub
          roles:
            - detect
        - path: rtsp://admin:PASSWORD@192.168.68.124:554/h265Preview_01_main
          roles:
            - record
            - audio
    audio:
      enabled: true
    detect:
      width: 640
      height: 360
      fps: 5
```

Same pattern for `back_yard` with that camera’s IP.

**Why split codecs:** Broadwell i5-5300U VAAPI struggles with HEVC on the *detect* path. Detect stays H.264 sub; record uses H.265 main (~2.6 GiB/h observed, CPU ~26–30% with 2 cams).

### Amcrest (`garden_view` @ `192.168.68.75`)

```
Detect (Extra/sub):  .../cam/realmonitor?channel=1&subtype=1
Record (Main):       .../cam/realmonitor?channel=1&subtype=0
```

**Required:** Amcrest Extra/sub stream = **H.264** (not H.265). HEVC on detect caused:

`No support for codec hevc profile 1` / VAAPI init failure.

With 3 cameras, Frigate CPU was ~40–50% — workable, limited headroom.

## 5. USB HDD for Frigate media (WD 1.8TB)

### Identify (Proxmox host)

```bash
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT,MODEL
# System SSD = sda — leave alone
# WD Passport = sdb (1.8T)
```

### Format + mount (wipes drive)

```bash
mkfs.ext4 -L frigate-storage /dev/sdb1

mkdir -p /mnt/frigate-storage
mount /dev/sdb1 /mnt/frigate-storage
df -h /mnt/frigate-storage

UUID=$(blkid -s UUID -o value /dev/sdb1)
echo "UUID=$UUID /mnt/frigate-storage ext4 defaults,nofail 0 2" >> /etc/fstab
# Actual UUID used: 6d2952d0-950d-452f-883e-38fb60281fc0
```

### Bind into LXC 101

```bash
mkdir -p /mnt/frigate-storage/media
chown 100000:100000 /mnt/frigate-storage/media

# /etc/pve/lxc/101.conf:
mp0: /mnt/frigate-storage/media,mp=/mnt/frigate-storage

pct reboot 101
pct exec 101 -- df -h /mnt/frigate-storage
```

### Point Docker at USB (inside LXC)

```bash
pct enter 101
cd /opt/frigate
docker compose stop frigate
rsync -a ./storage/ /mnt/frigate-storage/ 2>/dev/null || true
cp docker-compose.yml docker-compose.yml.bak
sed -i 's|./storage:/media/frigate|/mnt/frigate-storage:/media/frigate|' docker-compose.yml
docker compose up -d frigate
docker compose ps
df -h /mnt/frigate-storage
```

Observed storage rates (continuous estimate):

| Camera | GiB/h |
|--------|-------|
| front_door | ~2.63 |
| back_yard | ~2.64 |
| garden_view | ~1.74 |
| **Total** | **~7** (~168 GiB/day continuous; motion retain lasts longer) |

Do not unplug the USB while Frigate is running. `nofail` keeps the host bootable if the disk is missing.

Reusable guide: [STORAGE-USB.md](STORAGE-USB.md).
